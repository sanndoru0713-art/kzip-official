# 이미지 폴더 구조

실제 이미지가 준비되면 아래 위치에 넣고, 각 데이터 파일에서 경로를 지정하세요.

```
public/images/
├── projects/    # 프로젝트 이미지 (권장: 1600×1000 이상, webp/jpg)
├── insights/    # 인사이트 썸네일 (권장: 1200×675)
└── company/     # 회사·대표 프로필 이미지
```

## 프로젝트 이미지 교체 방법

1. `public/images/projects/의미있는-이름.jpg` 로 파일 추가
2. `src/data/projects.ts` 해당 항목에 `image: "/images/projects/의미있는-이름.jpg"` 지정
3. 화면의 `[이미지 교체 필요]` 자리표시자가 실제 이미지로 대체되도록
   컴포넌트에서 `PlaceholderImage` 대신 `next/image`를 사용하도록 확장할 수 있습니다.
   (자리표시자 유지 상태로도 사이트는 정상 동작합니다)

- AI 생성 추상 이미지는 사용하지 않습니다. 실제 프로젝트·현장 이미지를 사용하세요.
- 고객사 로고·실명은 공개 동의를 받은 뒤에만 게시하세요.
